## WOK Steam API

Steam data for developers, behind one API key: public inventories with item prices, player profiles, bans, CS2 float and inspect data, and FACEIT stats.

- **Games:** CS2, Rust, TF2, Dota 2, PUBG, s&box, Unturned and PAYDAY 2
- **Prices:** Steam Market and third-party markets; you choose the source per request
- **Batch:** many players and games in one streamed request
- **Migration:** SteamWebAPI-compatible inventory responses

Free key with 100 requests a day. Paid plans start at $12 per 30 days.

[Docs](https://woksteamapi.com/docs) · [Pricing](https://woksteamapi.com/pricing) · [Status](https://woksteamapi.com/status) · [OpenAPI](https://woksteamapi.com/api/openapi.json) · [Examples](https://github.com/woksteamapi/wok-api-examples)

```bash
pip install wok-api                 # Python SDK
npm install @woksteamapi/client     # JavaScript SDK
```
